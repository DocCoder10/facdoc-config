# facdoc-config

Configuration distante de l’application **facdoc**.

## Rôle
Ce dépôt contient les fichiers JSON permettant de :
- définir les classes (med1, med2, ...)
- définir les matières par semestre
- associer chaque matière à un dossier Google Drive

## Règles
- Lecture seule côté application
- Modifiable sans mise à jour de l’app
- Source de vérité pour la structure des cours
